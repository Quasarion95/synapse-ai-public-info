# app/web — то, что есть только в веб-версии

`app/` общая у веба и андроида: апк собирается из этой же папки (см.
`android/README.md`). Айфон — нативное приложение на Swift и эти файлы не
видит вовсе. Всё, что нужно только браузеру на компьютере, лежит здесь.

## Как это отделено

| Где | Что делается |
| --- | --- |
| `android/app/build.gradle` | `exclude 'web/**'` — в апк папка не попадает |
| `app/index.html` | подключает файлы, только если нет `window.AndroidVoice` (признак обёртки) |
| `app/app.js` | два хода к модулю: `finDesk()` и кнопка «Одним экраном» в полосе вкладок; без модуля оба молчат |
| `app/sw.js` | файлы в кэше оболочки — дашборд работает офлайн |

Считать здесь ничего своего нельзя: все суммы берутся функциями `app.js`
(`finMonthTotals`, `finByCat`, `finDebtSums`, `finDueThisMonth`…). Вторая
реализация той же арифметики разойдётся с первой на первой же правке.

## Что здесь сейчас

### `finance-desk.js` + `finance-desk.css` — «Мои финансы» одним экраном

Включается на окне от 1240 пикселей. Уже — обычные вкладки, как на телефоне.
Кнопка «Вкладками» в шапке дашборда переключает обратно, выбор запоминается
(`S.finLayout`); «Одним экраном» в конце полосы вкладок возвращает дашборд.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ Мои финансы            ‹ Октябрь 2026 ›                     [Вкладками]  │
├────────────┬───────────┬───────────┬───────────┬────────────┬────────────┤
│ Свободно   │ Пришло    │ Ушло      │ Отложено  │ Я должен   │ Мне должны │
├────────────┴───────────┴───────────┴───────────┼────────────┴────────────┤
│ Разбор месяца                                  │ Мои траты               │
│ полгода: пришло/ушло │ куда уходит, % к прошл. │ [Трата|Доход] кофе 350  │
│ темп: в день, прогноз на конец месяца          │ лента месяца по дням,   │
├───────────────┬────────────────┬───────────────┤ прокрутка внутри зоны   │
│ Конверты      │ Платежи месяца │ Долги         │                         │
│ полосы,       │ неоплаченные   │ просроченные  │                         │
│ остаток       │ сверху, Оплатить│ первыми      │                         │
├───────────────┴────────────────┴───────────────┤                         │
│ Копилки — карточки с темпом                    │                         │
└────────────────────────────────────────────────┴─────────────────────────┘
```

Уже 1200 пикселей по ширине самого дашборда — три колонки: лента справа на
высоту разбора и конвертов с платежами, долги и копилки — нижним рядом.

Связи между зонами:

- месяц один на весь экран — стрелки в шапке или щелчок по столбику;
- щелчок по категории в разборе оставляет в ленте только её, повторный — снимает;
- «Свободно» открывает правку остатка, «Оплатить», «Платёж», «Отложить» —
  те же окна, что во вкладках;
- «Вся таблица» и «Закрытые» уводят во вкладку с подробностями.
