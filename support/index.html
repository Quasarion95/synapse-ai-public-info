What to include in a report

  • what happened
  • what you expected instead
  • which screen you were on
  • whether the problem is repeatable
  • your app version and device model, if available

Common topics

  • AI replies are unavailable
  • tasks or goals behave unexpectedly
  • reminders or notifications do not appear
  • privacy or data deletion requests
  • purchase or restore issues

Current support path

Until a dedicated public inbox is live, support requests can be collected through the in-app bug report and idea report actions.

This page is designed to be used as the Support URL in App Store Connect.
