# Synapse для Android

Веб-версия из `../app`, упакованная в приложение. Не окно браузера над сайтом:
все файлы лежат внутри apk, приложение открывается офлайн.

## Почему здесь, а не в отдельном репозитории

Приложение и есть веб-версия. Отдельный репозиторий означал бы вторую копию
`app/`, которая молча отстаёт от первой — тот же класс поломок, что стоил нам
дня на расхождениях кэша. Здесь `../app` остаётся единственным исходником, а
Gradle копирует его в assets при каждой сборке.

## Как собрать

Инструменты лежат в `~/Developer/android-tools` и не трогают систему:

    source ~/Developer/android-tools/env.sh
    ~/Developer/android-tools/gradle-8.9/bin/gradle assembleDebug

Готовый файл — `app/build/outputs/apk/debug/app-debug.apk`.

## Что стоит знать, прежде чем менять

**Адрес `https://synapseapp.ru` внутри WebView настоящий по форме и локальный по
сути.** `WebViewAssetLoader` обслуживает его сам, в сеть не ходит. Домен выбран
не случайно: бэкенд выдаёт сессию ассистента только этому источнику, а
https-происхождение — защищённый контекст, без которого отключается половина
браузерных возможностей. Смените домен — Syn перестанет отвечать, и по логам
это будет выглядеть как «Origin не разрешён».

**Service worker исключён из сборки.** Внутри apk файлы и так локальные, а два
слоя кэша начали бы спорить и отдавать вчерашнюю версию.

**Обслуживаются два пути: `/app/` и `/fonts/`.** Начертания лежат соседней
папкой; без второго обработчика запрос за ними ушёл бы в настоящую сеть.
