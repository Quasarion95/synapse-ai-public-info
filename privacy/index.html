Privacy Policy

How Synapse AI handles data.

This page explains what data Synapse AI may process, how it is used, and what users can control or delete.

Back Support

1. What Synapse may process

Synapse may process tasks, goals, stages, notes, lists, interface settings, reminder preferences, and messages sent to the Syn assistant.

2. How data is used

This data is used to run the core planning features of the app, keep the workspace state consistent, and generate AI replies through Syn.

3. AI and external processing

When a user sends a message to Syn, the request is routed through the Synapse backend and then to the AI provider. If detailed context is enabled in the app settings, the request may include relevant goals, tasks, memory, and basic progress context needed to answer well.

4. Where data is stored

Most workspace data is stored on the device. Some assistant-related data, such as assistant profile memory and recent conversation context, may be stored on the backend to keep replies coherent between sessions.

5. User control and deletion

Users can edit or delete tasks, goals, notes, and lists inside the app. They can also clear Syn memory and reset the assistant context through in-app settings. This clears local assistant chat state and removes assistant profile memory on the backend.

6. Permissions

Synapse may request access to notifications, microphone, speech recognition, and Face ID. These permissions are optional and controlled by the user through iOS settings and app settings.

7. Security

Synapse relies on standard iOS security mechanisms where possible. Biometric data such as Face ID is handled by iOS and is not exposed directly to the app.

8. Third-party processing

AI replies may depend on third-party infrastructure providers used by the Synapse backend. This can include AI model routing and backend hosting needed to deliver Syn responses.

9. Website analytics

The synapseapp.ru website uses Yandex Metrica to count visits and see how the pages are used, including anonymised session recordings. This applies to the website only: the iOS app contains no advertising SDKs and no advertising identifier, and it is not tracked across other apps.

10. Contact and requests

Bug reports, suggestions, and privacy-related requests can be sent to support@synapseapp.ru, or started from the support actions inside the app.
